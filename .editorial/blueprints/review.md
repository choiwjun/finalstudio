# 리뷰 구조

이 템플릿은 `review` 글에 적용합니다. 도구, 물건, 서비스, 콘텐츠 평가입니다.

## 권장 순서

1. 사용 목적과 사용자 상황을 씁니다. 이 리뷰가 누구에게 유효한지 먼저 선을 긋습니다.
2. 평가 기준을 먼저 공개합니다. 판단은 기준 위에서만 합니다.
3. 실제 사용 기간과 사용 조건(버전·환경·빈도)을 밝힙니다.
4. 장점과 단점을 나눠 씁니다. 단점에 가장 구체적인 사례를 둡니다.
5. 추천하는 사람과 추천하지 않는 사람을 각각 한 문장으로 정리합니다.

## 작성 제약

- 사용하지 않은 기능을 평가하지 않습니다. 사용 범위를 명시합니다.
- 가격·정책·지원 범위는 확인 날짜와 출처를 붙입니다. 확인 전이면 마커로 남깅습니다.
- `모두에게 좋은 선택`이라는 결론을 금지합니다. 트레이드오프를 반드시 드러냅니다.
- 광고 문구와 제조사 설명 문장을 그대로 옮기지 않습니다.

## 출력 체크

- 평가 기준이 본문 판단보다 먼저 나오는가?
- 단점이 장점보다 구체적인가?
- 사용 조건(기간·환경)이 명시되어 있는가?
- 추천·비추천 대상이 각각 드러나는가?
