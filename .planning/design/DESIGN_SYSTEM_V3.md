# WJ Blog — Personal Editorial 디자인 시스템 v3

작성일: 2026-09-06 (Asia/Seoul)
상태: 활성 기준. `DESIGN_SYSTEM_V2.md`(Signal Archive)와 Blocksy News 기반 v3 제안은 의사결정 이력으로 보존한다.

## 1. 제품 정의

- 제품 유형: **Personal Editorial Blog / 개인 기록형 블로그**
- WJ Blog는 여러 글쓰기 주제(에세이, 경험 기록, 리뷰, 사용법, 여행, 책, 사진)를 담는 개인 블로그다.
- `업무도구`, `AI 업무 활용`은 브랜드가 아니라 여러 카테고리 중 하나다.
- 참고 조합: Ghost Solo의 개인성 + Webflow Nodes의 범용 정보 구조 + AstroPaper의 읽기·접근성 기본기 + Blocksy의 익숙한 글 목록 리듬.

## 2. 정보 구조

### 홈 흐름 (고정)

```
블로그 이름·짧은 개인 소개 → 대표 글 또는 최근 글 → 최신 글 목록 → 카테고리 → 소개·아카이브 진입 → 푸터
```

- 첫 화면에서 개인 블로그와 최신 글이 바로 이해되어야 한다.
- 검색은 헤더의 보조 기능이고 검색 페이지(`/search`)로 연결한다. 홈 첫 화면에 검색 히어로를 두지 않는다.
- 대표 글은 카테고리 대표가 아니라 최근 글 또는 사람이 선택한 글이다.
- 읽기 큐, 번호형 목록 연출 같은 도구형 아카이브 장치를 사용하지 않는다.

### 글 상세 흐름 (고정)

```
카테고리·날짜·읽는 시간 → 제목·요약 → 본문 → 선택적 이미지·출처·검증 정보 → 관련 글
```

- `테스트`, `검증 상태`, `사용 환경` 패널은 데이터가 있는 글에만 표시한다.
- 에세이·여행·책·사진 글에는 검증 UI를 렌더링하지 않는다.
- 관련 글은 `series`가 없어도 카테고리로 연결할 수 있다.

### 카테고리

- 카테고리는 글 데이터(`topic`)에서 동적으로 구성한다.
- 특정 카테고리를 메뉴 첫 항목, 색상 대표값, 브랜드 문구로 고정하지 않는다.

## 3. 디자인 토큰 (tokens.css 단일 소유)

v2의 토큰 구조를 유지한다. 색상 전면 교체는 하지 않는다.

- 표면: `--site-bg` 밝은 중성 배경, `--site-surface` 카드·본문 표면
- 잉크: `--site-ink` 본문, `--site-ink-soft` 보조, `--site-muted` 메타
- 강조: `--site-accent` 링크·행동, `--site-warm` 포인트 (브랜드 신호 아님)
- 선: `--site-line`, `--site-line-strong`
- 본문 폭: `--site-prose: 46rem`, 페이지 폭: `--site-max: 74rem`
- 타이포: 시스템 한글 sans 스택, 본문 `--leading-body: 1.78`

규칙:

1. 색상·간격·타이포 토큰은 `tokens.css`에서만 정의한다. `site.css`와 `global.css`는 토큰을 소비만 한다.
2. 공개 UI 컴포넌트 규칙은 `site.css`가 단일 소유한다. `global.css`는 리셋·본문 요소만 담당한다.
3. 관리자 쉘(`shell="admin"`)은 공개 블로그 템플릿과 분리한다.

## 4. 컴포넌트 규칙

### 카드 / 목록 항목

- 기본 표시: 제목·요약·날짜·읽는 시간·카테고리. 이미지는 선택.
- 이미지가 없는 글도 같은 완성도로 보이는 텍스트형 항목을 기본으로 한다.
- 카테고리 배지는 텍스트 라벨이며 카테고리별 고정 색상을 만들지 않는다.

### 검증 메타 (조건부)

- `testedAt`, `toolVersions`, `sourceIds`는 frontmatter에 데이터가 있을 때만 렌더링한다.
- 데이터가 없는 글에 "사람 검토 전" 같은 상태 문구를 기본 노출하지 않는다.

### 헤더 / 푸터

- 헤더: 블로그 이름 + 글/카테고리/소개 + 검색 링크.
- 푸터: 소개·작성자·문의·개인정보처리방침·편집 원칙.

## 5. 반응형 기준

- 1440px: 최신 글 목록과 보조 영역이 한 화면에서 구분된다.
- 1024px/768px: 보조 영역을 본문 아래로 이동, 목록은 1열 유지.
- 390px: 헤더·대표 이미지·카드가 잘리지 않고, 표·코드 내부 스크롤만 허용하며 페이지 가로 overflow 금지.

## 6. 접근성 기준

- 스킵 링크, `aria-current`, `aria-live` 검색 상태 유지.
- 키보드 순회와 포커스 링(`--shadow-focus`) 유지.
- 200% 확대에서 레이아웃 붕괴 없음.

## 7. 콘텐츠·생성 규칙 연계

- 생성 페르소나는 `업무 생산성 전문가`가 아니라 **개인 편집자 겸 기록자**.
- `사용법` 글에만 단계·오류·검증 규칙을 강하게 적용한다.
- 편집 헌법·금지 규칙·사실 검증·사람 승인 절차는 자가 개선으로 변경하지 않는다.

## 8. v3 완료 기준

- 처음 방문한 사람이 3초 안에 개인 블로그의 최신 글과 이동 경로를 이해할 수 있다.
- 업무 도구 글이 없어도 홈이 비어 보이지 않는다.
- 공개 화면 어디에도 업무·실무·검증이 브랜드명이나 대표 메시지로 보이지 않는다.
- 출처·테스트·도구 버전은 필요한 글의 신뢰 정보로만 표시된다.
- 390px에서 가로 overflow와 잘린 핵심 컨트롤이 없다.
