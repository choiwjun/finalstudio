# WJ Blog v2 — Signal Archive

작성일: 2026-09-06
상태: 구현 중 — 2번의 탐색 구조와 3번의 아카이브 리듬을 결합한 재설계

## 방향

WJ Blog는 일반적인 개인 블로그 템플릿이 아니라, 직접 확인한 실무 지식을 빠르게 찾고 끝까지 읽는 **검증형 지식 아카이브**로 보인다.

- 2번 시안에서 검색 우선 진입, 대표 글, 번호가 있는 읽기 큐를 가져온다.
- 3번 시안에서 따뜻한 중립 배경, 넓은 여백, 세로 규칙선, 기록물 같은 탐색 리듬을 가져온다.
- 관리자 화면은 공개 블로그와 분리된 어두운 운영 쉘을 사용한다.

## 시각 규칙

- 배경: 따뜻한 회백색, 콘텐츠 표면: 거의 흰색
- 주 행동색: 전기 파랑 하나
- 보조 신호색: 코럴 하나
- 공개 헤더: 짙은 네이비
- 본문은 카드보다 정렬·여백·규칙선으로 묶는다.
- 둥근 카드 그리드, 장식용 통계, 과도한 배지, 그라디언트, 글리프 아이콘을 사용하지 않는다.
- 제목·본문·메타의 대비를 명확히 하고 같은 강도의 정보가 한 화면에 겹치지 않게 한다.

## 화면별 역할

### 홈

`검색 → 오늘의 읽을 글 → 최근 읽기 큐 → 주제 지도` 순서다. 공개 글이 없을 때에도 검색과 운영 원칙은 살아 있어야 하며, 빈 상태가 개발 중 화면처럼 보이지 않아야 한다.

### 글 상세

제목·요약·검증 정보가 첫 화면의 중심이다. 빠른 답변·사실 정보·목차는 본문을 방해하지 않는 선에서 한 번씩만 노출하고, 본문은 한 열의 긴 읽기 흐름으로 유지한다. 데스크톱 보조 정보는 읽기 위치를 잃지 않게 우측에 고정한다.

### 관리자

공개 헤더를 재사용하지 않는다. `검토 큐 → 글 현황 → 발행 흐름` 순서의 운영 작업 공간으로 보이며, 통계는 카드보다 구획 셀과 숫자 대비로 표현한다.

## 구현 원칙

- `src/styles/tokens.css`가 색상·타이포·간격·레이아웃 토큰의 단일 기준이다.
- `src/styles/site.css`가 공개 사이트와 관리자 표면의 컴포넌트 규칙을 소유한다.
- 새로운 화면은 먼저 사용자의 주 행동을 정하고, 그 행동을 기준으로 섹션을 배치한다.
- 페이지 전체 가로 스크롤은 금지하고 표·코드만 내부 스크롤을 허용한다.
- 390px에서 헤더·검색·읽기 큐·본문·관리자 표가 화면 밖으로 밀려나지 않아야 한다.
