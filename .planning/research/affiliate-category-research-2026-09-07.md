# 쇼핑 커넥트·쿠팡 파트너스: 채널 조건과 카테고리 제안

- 조사일: 2026-09-07. 공개 1차 자료만 사용했다.
- 범위: 기존 Astro 독립 블로그 `업무도구 실전`에서 제휴 수익화를 준비한다. 최우선은 일관된 글쓰기 페르소나다.
- 상태: 기획 근거. 가입 승인, 실제 링크 발급, 해당 도메인의 실적 집계·정산은 검증하지 않았다.
- **검색량·블로그 유입량·전환율을 측정하지 않았다. 아래 키워드는 검색 의도 가설이지 검색량 순위가 아니다.**

## 1. 핵심 결론

1. **쇼핑 커넥트가 네이버 채널에서만 가능하다는 주장은 틀리다.** 공식 가입 안내에는 Instagram과 YouTube도 있다. 2026.08 통합 약관은 `미디어`를 크리에이터가 이용하는 PC/모바일웹, 모바일앱 등 온라인 공간으로 정의하고, 발급 링크를 미디어에 게재하는 활동을 규정한다. 따라서 독립 웹사이트에 게시하는 경로는 약관상 조건부로 뒷받침된다. [N1–N3]
2. **독립 Astro 도메인만으로 가입 연동 조건을 충족한다는 뜻은 아니다.** 브랜드 커넥트 크리에이터 가입 후 채널을 1개 이상 연동한 스페이스가 필요하다. 공개 연동 안내는 블로그·클립·Instagram·YouTube를 열거한다. 임의의 독립 도메인을 가입 채널로 연동하는 기능은 확인하지 못했다. 먼저 실제 보유한 지원 채널로 가입 조건을 확인해야 한다. [N1–N2]
3. **쿠팡 파트너스는 독립 홈페이지·도메인·웹사이트 사용을 공식적으로 설명한다.** 다만 광고를 게시할 미디어를 등록하고, 심사를 받아야 한다. Astro라는 기술보다 실제 도메인 등록과 공개 콘텐츠 품질이 관건이다. [C1–C3]
4. **권장 편집 축은 ‘작은 업무 불편을 줄이는 도구와 환경’이다.** 키보드 추천만 하는 쇼핑몰형 블로그보다, 문제 해결 글과 실제 비교 글을 연결한다. 이는 수익 보장이 아니라 기존 정체성·검증 비용·차별화 가능성을 고려한 기획 판단이다.
5. **페르소나는 편집 관점과 목소리이지 허구의 사용경력이나 가상의 전문가 이력이 아니다.** 쿠팡 공식 FAQ는 AI 가상인물이 추천·보증하면 가상인물 표시를 요구하고, 사용 경험 주장이 실제 경험적 사실과 다르면 부당 표시·광고가 될 수 있다고 설명한다. [C3]

## 3. 표시 문구와 글쓰기 페르소나

### 공식 문구와 위치

- 네이버 공식 안내 문구: **“이 포스팅은 네이버 쇼핑 커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.”** [N8–N9]
- 쿠팡 공식 FAQ 권장 예시: **“이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.”** [C3]
- 네이버 블로그 가이드는 제목 앞·본문 최상단의 명확한 표시를 안내한다. 쿠팡 FAQ는 제목 또는 첫 부분에 명확하게 표시하고, 첫 부분 표시 시 크기·색상 등으로 쉽게 인식하게 하라고 설명한다. 독립 블로그 설계에서는 **본문 최상단에 상시 보이는 텍스트**를 기본으로 잡는 것이 보수적이다. 푸터 전용, 접힌 영역, 이미지 속 작은 글씨는 사용하지 않는다. 이는 공식 프로그램 안내를 적용한 설계 제안이며 별도의 법률 자문이 아니다. [N9, C3]
- 두 프로그램 링크가 함께 있으면 각각의 경제적 관계를 구분하여 표시한다. 문구를 합성해 공식 권장 문구라고 부르지 않는다.
- 네이버 `#내돈내산` 기능은 쇼핑 커넥트 링크와 함께 사용할 수 없다고 공식 가이드가 설명한다. 실제 자비 구매라도 제휴 수수료 관계는 별도로 표시해야 한다. [N9]

### 제안 페르소나: ‘업무 마찰을 줄이는 기록자’

이름·직업·나이·전문가 자격은 실제 사용자 정보로 확인하기 전 만들지 않는다. 다음은 사실 주장이 아니라 편집 규칙 제안이다.

- 독자: 작은 책상과 제한된 예산으로 문서 작업·회의·학습을 하는 사람.
- 약속: 먼저 불편을 좁히고, 기존 도구로 해결할 수 있는지 확인한 다음, 필요할 때만 구매를 권한다.
- 말투: 짧고 담백하게. ‘무조건’, ‘인생템’, ‘누구에게나 최고’보다 조건과 제외 대상을 쓴다.
- 문서 구조: 상황 → 확인 조건 → 선택 기준 → 실제 확인 결과/공식 사양 → 단점 → 사지 않아도 되는 경우 → 관련 도구 링크.
- 증거 표기: `직접 사용`, `직접 측정`, `공식 문서 조사`, `미확인`을 구분한다. 사용하지 않았다면 ‘써보니’라고 쓰지 않는다.
- 구매 가이드와 직접 리뷰를 구별한다. 자기 돈으로 샀다는 사실도 영수증·기록 없이 만들지 않는다.
- 가상의 소비자나 전문가가 제품을 쓰고 추천하는 설정은 피한다. 꼭 사용한다면 실제 경험 사실 여부와 가상인물 표시를 모두 검토해야 한다. AI 문체 보조와 AI 가상인물 추천은 같은 개념이 아니다. [C3의 AI FAQ; N3 제8조]

## 4. 카테고리 후보: 수요 근거와 가설을 분리

### 확인된 수요 자료의 범위

- 국가데이터처의 2026년 7월 온라인쇼핑동향(2026-09-01 게시)은 온라인쇼핑 거래액 25조 954억원, 전년동월 대비 7.3% 증가, 모바일 비중 78.0%를 보고한다. 이는 국내 온라인 구매가 존재하는 거시적 근거다. 특정 블로그 카테고리의 검색량이나 수익을 증명하지 않는다. [D1]
- 같은 발표에서 음식서비스·음식료품·자동차 및 자동차용품 증가, 의복 감소를 확인했다. 음식서비스의 크기를 데스크 도구 매출 전망으로 전용하지 않는다. 단일 월 증감으로 장기 추세를 단정하지 않는다. [D1]
- 네이버 쇼핑인사이트는 네이버 통합검색 쇼핑 영역과 네이버쇼핑의 **검색 클릭 추이**를 제공한다. API의 `ratio`는 최대값을 100으로 둔 상대값이지 검색건수나 구매건수가 아니다. [D2]
- 이번 환경에서 쇼핑인사이트 공개 UI가 접근 오류로 이동했고 API 클라이언트 인증정보가 없어 실제 키워드 시계열을 얻지 못했다. **아래 후보 중 ‘측정된 인기 키워드’는 없다.** 분야별 거래 통계의 추가 검증은 별도 수요 조사 보고서와 함께 해석한다.

1. 사용자에게 실제 직무·보유 도구·직접 테스트 가능 범위를 확인한다. 페르소나는 여기서 확정한다.
