# 블로그 제휴 상품 카테고리: 수요 근거와 잠정 실행순위

- 조사일: 2026-09-07.
- 대상: 엑셀 생산성에서 출발하는 한국어 Astro 개인 블로그. 글 쓰는 사람의 관점이 주축이다.
- 결론: **데스크·업무 주변기기 → 작은 집 수납·생활 → 청소·세탁 소형가전 → 여행 소품** 순으로 작은 실험을 권한다. 이는 **검색량 순위가 아니라 이 블로그의 실행 우선순위**다.
- 제휴 가입 자격·수수료·표시 정책은 별도 조사 범위다. 이 문서는 이를 판정하지 않는다.

## 1. 먼저 구분해야 할 세 가지

| 지표 | 무엇을 보여 주나 | 무엇을 증명하지 못하나 |
| --- | --- | --- |
| 온라인쇼핑 거래액 | 온라인에서 실제 결제되는 광범위 상품군의 금액 | 검색 횟수, 해당 세부 제품의 수요, 개인 블로그 유입·수익 |
| 네이버 쇼핑인사이트 | 네이버 통합검색 쇼핑 영역·네이버쇼핑의 검색 클릭 추이, 정규화된 상대지수 | 절대 검색량, 네이버 전체 검색량, 외부 Astro 블로그에 배분되는 클릭 |
| 내 블로그 검색 노출·클릭 및 제휴 성과 | 실제 발행한 글이 받은 유입과 후속 행동 | 아직 발행하지 않은 카테고리 전체의 잠재 수요 |

큰 거래액은 후보 시장을 고르는 배경 자료다. 이를 “검색 유입이 많다” 또는 “이 블로그가 돈을 번다”로 바꾸어 쓰면 안 된다.

### B. 네이버 데이터랩: 측정 정의는 확인, 후보별 실제 지수는 미확보

- [쇼핑인사이트 공식 화면](https://datalab.naver.com/shoppingInsight/sCategory.naver)
- [네이버 공식 쇼핑인사이트 API 문서](https://developers.naver.com/docs/serviceapi/datalab/shopping/shopping.md)
- 확인일: 2026-09-07. API 설명은 지표 정의이며 이번 후보의 관측 기간을 가진 실측 데이터가 아니다.

공식 문서의 설명은 “네이버 통합검색의 쇼핑 영역과 네이버쇼핑에서의 검색 클릭 추이 데이터”다. `results.data.ratio`는 “구간별 결과에서 가장 큰 값을 100으로 설정한 상댓값”이다. 분야별 트렌드 요청은 최대 세 분야를 비교하며, 키워드별 트렌드 기능도 있다. API 호출에는 발급받은 클라이언트 아이디·시크릿이 필요하다.

이번 직접 HTTP 조회에서는 쇼핑인사이트 화면이 HTTP 200을 반환했지만 내용은 **서비스 접근 오류**였다. API 인증정보도 제공되지 않았다. 따라서 **후보 네 분야의 지수, 인기 키워드 순위, 월간 검색량을 확보했다고 주장하지 않는다.** 서비스 전체가 폐지되었다는 뜻도 아니다. 개발자 문서의 예시 데이터를 현시점 수요 데이터로 사용하지 않았다.

## 3. 이 블로그의 잠정 실행순위 — 판단과 사실을 분리

아래의 제품·글감은 **테스트 후보**다. 검색량을 검증한 키워드 목록이 아니다. 수납과 소형가전의 순서는 실제 보유 제품과 글감이 다르면 바꿔도 된다.

| 순위 | 방향 | 확인된 배경 근거 | 이 블로그에 대한 판단·가설 | 첫 글감 후보 |
| --- | --- | --- | --- | --- |
| 1 | 홈오피스·데스크 주변기기 | 컴퓨터·주변기기 거래액 +12.9% YoY. 관련 상품이 온라인에서 거래되는 시장은 확인. | 엑셀 작업과 글쓰기 경험을 같은 독자 문제로 연결하기 가장 쉽다는 편집 판단. 검색 경쟁 우위는 미검증. | 엑셀 숫자 입력용 키보드의 배열·숫자패드 선택, 작은 책상에서 모니터·노트북 배치, 장시간 글쓰기 환경의 실제 사용기 |

**우선 행동:** 카테고리 네 개를 동시에 개설하지 말고, 기존 생산성 글에 연결되는 데스크 문제 해결 글부터 검증한다. “추천 TOP 10”보다는 작업 맥락·실측·제약·사지 않아도 되는 조건을 보여 주는 글을 실험한다. 이 역시 운영 제안이지 공식 자료가 증명한 성공 공식은 아니다.

## 4. 실용 측정 계획

이 절의 기간·개수는 실험 설계 제안이다. 외부 통계 수치가 아니다.

### 발행 전: 수요와 유입 가능성을 따로 조사

1. 데이터랩을 브라우저 또는 정식 API로 열고 **2025-09-01~2026-08-31** 월별 추이를 조회한다. 직전 완결 12개월의 후보 창이다. 실제 제공 여부를 확인하고, 불가하면 가용 기간을 명시한다.
2. 업무 주변기기·수납·청소·여행용품을 상품 단위로 쪼갠다. 실제 네이버쇼핑 분류에서 확인한 카테고리 코드와 동의어 묶음을 기록한다. 서로 크기가 다른 대분류를 세부 상품의 수요처럼 비교하지 않는다.
3. 동일한 기간·기기·성별·연령 조건으로 조회한다. API 비교 한도 때문에 요청을 나눌 때 **각 요청의 100을 같은 절대량처럼 비교하지 않는다.** 공통 기준 분야를 포함하고 정규화 방식·분모를 확인하기 전에는 통합 순위를 만들지 않는다.
4. 후보별 검색 결과를 직접 점검한다. 상품 영역·공식몰·동영상·블로그·외부 웹문서가 어떤 의도에 노출되는지 기록한다. 네이버 블로그에 보이는 기회를 외부 Astro 사이트에도 그대로 적용하지 않는다.
5. 검색어를 `문제 해결`, `선택·비교`, `제품명·사용기`로 나눈다. 예: “엑셀 숫자 입력 키보드”, “책상 케이블 정리”, “청소기 세척 방법”. 예시는 모두 미검증 후보다.

### 발행 후: 실제 블로그 성과로 순위 수정

- 데스크 글과 그에 인접한 수납 글을 소규모로 발행한다. 우선 각 2편 정도를 같은 품질 기준으로 만들고, 색인 확인 후 6~8주 관찰한다. 작은 표본이므로 승패를 단정하지 않는다.
- 글별 최초 색인일, 검색 노출, 검색 클릭, 실제 랜딩 방문, 유입 검색어, 상품 링크 클릭을 기록한다. Google Search Console 및 네이버 서치어드바이저에서 해당 사이트에 실제 제공되는 지표를 확인한다. 도구마다 집계 정의가 다를 수 있으므로 하나의 수치로 섞지 않는다.
- 이후 제휴 대시보드에서 제공되는 경우 클릭·주문·확정 수익·취소를 따로 기록한다. 주문액을 확정 수익으로 취급하지 않는다. 승인된 추적 식별자 등으로 글별 귀속이 가능한 범위만 연결하고, 불가능하면 사이트/계정 합계로 별도 보고한다. 전체 검색 방문의 구매 전환율로 간주하지 않는다.
- 핵심 연결은 `검색 노출 → 검색 클릭/방문 → 상품 링크 클릭 → 확정 수익`이다. 각 단계의 모수가 다르므로 클릭률의 분모를 반드시 붙인다.
- 페이지 공개일·색인일·게시 후 경과일·제작 시간도 기록한다. 오래된 글과 새 글의 누적 유입을 단순 비교하지 않는다.
- 노출이 적으면 먼저 색인·검색의도 적합성을 본다. 노출은 있으나 클릭이 적으면 제목·설명을 본다. 방문은 있지만 상품 링크 클릭이 없으면 글의 구매 판단 도움 여부를 본다. 클릭 이후 판매 부진은 제품·가격·판매 조건 등 별도 문제일 수 있다.
- 충분한 노출 또는 실제 검색어가 쌓이기 전에는 “이 카테고리는 수요가 없다”고 결론 내리지 않는다. 생산성 글에서 들어온 실제 독자 반응이 거시 거래액 순위보다 이 사이트의 확장 판단에 직접적이다.

## 5. 검증 로그와 남은 불확실성

- `websearch`/`factchk` 지침을 읽고 적용했다. Serper 키가 없어 검색 도구는 사용할 수 없었다. 공식 사이트에 직접 접근해 본문과 PDF를 확인했다. 검색 결과 요약만으로 채택한 수치는 없다.
- 공식 PDF는 메모리에서 텍스트를 추출했다. 국가데이터처 표의 열 제목·단위·기간과 네이버 IR 문구를 함께 대조했다.
- KOSIS 연결 목록은 접근했지만 동적 통계표 수치를 별도로 추출하지 않았다. 거래액 숫자의 직접 근거는 동일 조사 발행기관의 공식 PDF다.
- **확인:** 온라인 거래 시장은 존재하고 위와 같은 광범위 상품군의 규모·증감이 보고됐다. 스마트스토어 전체 거래액도 성장했다. 데이터랩은 상대 클릭지수다.
- **미확인:** 네 후보의 절대 검색량, 세부 상품 수요 순위, 검색 경쟁도, 외부 블로그 획득 가능 클릭, 제휴 전환율·수익, 실제 독자의 관심 분포.
- **잠정 판단:** 글쓰기·엑셀이라는 출발점에는 데스크와 인접 수납이 자연스럽다. 후속 실측으로 이 판단을 바꿀 수 있어야 한다.
