Excel 표를 Word 보고서에 붙인 뒤 셀 너비나 글꼴이 달라져 모양이 흐트러졌다면, 표를 셀로 붙이는 대신 **연결된 그림**으로 넣어 보세요. 원본 범위를 그림처럼 보여주면서 Excel의 값이 바뀌었을 때 문서에서도 갱신할 수 있습니다.

먼저 선택 기준부터 정리하면 간단합니다.

> - 보고서 숫자가 계속 바뀐다면 **연결된 그림**
> - 제출이 끝난 고정본이라면 **그림**

이번 글은 Windows Microsoft 365 Excel 16.0의 한국어 화면을 기준으로, Excel 범위를 Word에 붙여 넣고 원본 값을 바꿔 갱신하는 흐름을 설명합니다. Excel 2016·2019·2021·2024에서는 메뉴 이름이나 아이콘 위치가 다를 수 있습니다.

## 그림과 연결된 그림 중 무엇을 선택할까?

| 붙여넣기 방식 | 원본을 수정하면 | 원본 파일이 없을 때 | 적합한 상황 |
| --- | --- | --- | --- |
| 그림 | 바뀌지 않음 | 그대로 보임 | 최종 제출본, 공유용 스냅샷 |
| 연결된 그림 | 링크를 갱신하면 반영됨 | 갱신할 수 없음 | 숫자가 계속 바뀌는 보고서 |

연결된 그림은 원본 파일의 위치와 이름을 참조합니다. Word 파일만 동료에게 보내면 그림은 보일 수 있어도 이후 갱신은 되지 않을 수 있으므로, 최종 제출 전에는 그림으로 고정할지 결정해야 합니다.

## 방법 1. 붙여넣기 옵션에서 연결된 그림 선택

### 1) Excel에서 범위 복사

원본 시트에서 보고서에 넣을 범위를 선택하고 `Ctrl + C`를 누릅니다. 제목 행과 필요한 숫자를 한 번에 선택해야 Word에서도 같은 범위가 보입니다.

![Excel에서 표 범위를 선택한 화면](/images/excel-linked-picture-2.png)
*그림 1. Excel에서 Word로 옮길 범위를 선택한 화면*

### 2) Word에서 붙여넣기 메뉴 열기

Word에서 범위를 넣을 위치를 클릭한 뒤 **홈 → 붙여넣기** 아래 화살표를 엽니다. 일반 붙여넣기 아이콘만 바로 누르면 셀 표나 서식이 포함된 개체로 들어갈 수 있으므로, 옵션 목록을 먼저 확인하세요.

![Excel의 붙여넣기 옵션 갤러리](/images/excel-linked-picture-3.png)
*그림 2. Excel 범위를 Word에 붙여 넣을 때 확인할 옵션 목록*

### 3) 연결된 그림 선택

옵션에서 **연결된 그림**을 선택합니다. Word에는 범위가 한 장의 그림처럼 들어가고, 셀 너비가 Word 문서에 맞지 않아 표가 무너지는 문제를 줄일 수 있습니다.

![Word에서 선택된 연결 그림 개체](/images/excel-linked-picture-4.png)
*그림 3. Word 문서에 들어온 연결 그림 개체*

### 4) 원본을 바꾸고 갱신 확인

Excel 원본의 숫자 하나를 바꾼 뒤 Word로 돌아옵니다. 그림을 선택하고 링크 갱신 명령을 실행해 변경된 값이 반영되는지 확인하세요.

이번 실측에서는 Q2의 `156`을 `222`로 바꾸고 링크를 갱신했습니다.

![원본 값 변경 후 갱신된 연결 그림](/images/excel-linked-picture-5.png)
*그림 4. Excel 원본의 변경값 `222`가 Word 그림에 반영된 화면*

값이 갱신되지 않는다면 원본 통합 문서의 이름이나 폴더가 바뀌었는지 먼저 확인하세요. 연결된 그림은 원본 위치가 바뀌면 참조를 잃을 수 있습니다.

## 방법 2. 자주 쓰면 카메라 도구 추가

같은 범위를 매주 보고서에 넣는다면 카메라 도구를 빠른 방법으로 사용할 수 있습니다.

1. Excel에서 **파일 → 옵션 → 리본 사용자 지정**을 엽니다.
2. 명령 선택에서 **리본에 없는 명령**을 선택합니다.
3. **카메라**를 원하는 탭과 그룹에 추가하고 확인을 누릅니다.
4. 범위를 선택한 뒤 카메라를 누르고 Word에 그림을 배치합니다.

![Excel 옵션의 리본 사용자 지정 화면](/images/excel-linked-picture-6.png)
*그림 5. Excel 옵션에서 카메라 도구를 추가하는 화면*

카메라 도구는 붙여넣기 메뉴를 매번 열지 않아도 된다는 점이 장점입니다. 처음 설정하는 시간이 필요하므로 한두 번만 사용할 때는 방법 1이 더 빠릅니다.

## 갱신되지 않거나 흐릿할 때

- **연결된 그림이 목록에 보이지 않음**: 메모장이나 일부 웹 편집기는 Excel 연결 개체를 지원하지 않습니다. Word·PowerPoint처럼 Office 앱에서 다시 시도하세요.
- **원본을 바꿔도 값이 그대로임**: Excel 파일의 이름·폴더가 바뀌었거나 링크 갱신이 실행되지 않았을 수 있습니다. 원본 파일을 원래 위치에 두고 링크를 갱신하세요.
- **선택한 범위 밖의 행이 보이지 않음**: 연결은 처음 선택한 범위에 고정됩니다. 행이 늘어날 표라면 여유 범위를 포함하거나 새 범위로 다시 붙여 넣어야 합니다.
- **그림이 흐릿함**: 원본 배율, Windows 화면 배율, 문서에서의 확대 비율이 영향을 줄 수 있습니다. 원본을 100% 배율에서 다시 복사해 비교하세요. [직접 확인 필요: 고DPI 환경별 흐림 정도]
- **동료 PC에서 갱신되지 않음**: Word 파일과 원본 Excel 파일의 경로가 다르면 링크를 갱신할 수 없습니다. 공유·제출용이라면 마지막에 **그림**으로 고정하는 편이 안전합니다.

## 자주 묻는 질문

### Excel 웹 버전에서도 연결된 그림을 사용할 수 있나요?

데스크톱 Excel에서 확인한 메뉴와 웹용 Excel의 지원 범위가 같다고 단정하기 어렵습니다. 웹용 Excel을 주로 사용한다면 **직접 확인 필요: 웹용 Excel의 연결된 그림 지원 여부**입니다. 지원되지 않는 환경에서는 화면 캡처나 일반 그림 붙여넣기를 대안으로 사용하세요.

### PDF로 저장하거나 인쇄해도 보이나요?

Word 문서 안에 그림 개체로 표시되므로 PDF 변환과 인쇄에는 포함됩니다. 다만 변환 결과의 선명도는 원본 배율과 Word의 그림 압축 설정에 영향을 받습니다.

### 원본 시트나 파일을 삭제하면 어떻게 되나요?

연결 대상이 사라지면 더 이상 새 값을 갱신할 수 없습니다. 마지막 화면이 남을지 오류가 표시될지는 문서와 링크 상태에 따라 달라질 수 있으므로, 원본을 삭제하기 전에 그림으로 붙여 넣어 고정하세요. [직접 확인 필요: 원본 시트·파일 삭제 후 실제 표시 상태]

## 정리

보고서가 계속 바뀌면 Excel 범위를 `Ctrl + C`로 복사한 뒤 Word의 붙여넣기 옵션에서 **연결된 그림**을 선택합니다. 숫자 갱신이 끝난 제출본이라면 같은 메뉴의 **그림**으로 바꿔 원본 의존성을 끊습니다.
