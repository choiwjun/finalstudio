엑셀 표가 깨져서 붙는 이유는 표를 "셀 덩어리"로 복사하기 때문이에요. 해답은 복사 방식을 바꿔 **표를 그림으로 붙여넣는 것**, 그중에서도 원본과 연결이 살아 있는 **연결된 그림**이에요. 붙여넣은 표는 그림처럼 절대 깨지지 않고, 원본 숫자를 고치면 함께 갱신돼요. 이번 실측에서는 원본 값을 바꾼 뒤 연결 개체의 갱신 명령을 실행해 화면 변화를 확인했어요. 자동 갱신 시점은 문서·Office 설정에 따라 달라질 수 있으니 제출 전 한 번 더 확인하세요.

![Word에 편집 가능한 표로 들어간 Excel 범위](/images/excel-linked-picture-1.png)
*그림 1. Excel 범위를 Word 표로 넣은 실측 화면*

> **핵심 요약**
> - 복사(`Ctrl + C`) → 붙여넣기 아래 화살표 → **연결된 그림** 순서면 설정 없이 끝나요
> - 연결된 그림은 원본 시트와 맞닿아 있어서, 원본 숫자를 고치면 그림도 함께 바뀌어요
> - 갱신이 필요 없는 확정 자료라면 **그림**(스냅샷)을 고르면 돼요

이 글은 Microsoft 365(2026-09 기준, 한국어 화면) 기준으로 설명해요. 이번 화면 실측은 Windows의 Microsoft 365 버전 16.0에서 진행했으며, Excel 2016·2019·2021·2024는 메뉴가 다를 수 있어요.

## 방법 1 — 설정 없이 10초 만에: 그림 연결 붙여넣기

별도 설정 없이 복사·붙여넣기만으로 끝나는 방법이에요. 워드·파워포인트·아웃룩으로 옮길 때 모두 같은 절차예요.

1. 원본 시트에서 옮길 표 범위를 선택하고 `Ctrl + C`를 누르세요. 이때 표 서식이 적용된 범위를 통째로 선택해야 서식까지 그대로 담겨요.

![Excel에서 표 범위를 선택한 화면](/images/excel-linked-picture-2.png)
*그림 2. Excel에서 표 범위를 선택한 실측 화면*

2. 붙여넣을 문서에서 **홈 → 붙여넣기 아래 화살표**를 눌러 옵션 목록을 펼치세요.

![Excel의 붙여넣기 옵션 갤러리](/images/excel-linked-picture-3.png)
*그림 3. Excel 한국어 화면의 붙여넣기 옵션 갤러리*

3. 목록에서 **연결된 그림**을 선택하세요. 표가 한 장의 그림으로 딱 붙어요.

![Word에서 선택된 연결 그림 개체](/images/excel-linked-picture-4.png)
*그림 4. Word에서 연결 그림 개체를 선택한 실측 화면*

4. 원본 시트에서 숫자 하나를 고치고, 문서 속 그림이 바뀌는지 확인하세요. 이번 실측에서는 Q2의 `156`을 `222`로 바꾼 뒤 링크 갱신을 실행했고, 아래 화면에서 값이 `222`로 바뀐 것을 확인했어요.

![원본 값 변경 후 갱신된 연결 그림](/images/excel-linked-picture-5.png)
*그림 5. 원본 값 변경 후 연결 그림에 반영된 화면*

갱신이 필요 없는 한 장짜리 스냅샷이라면 같은 자리에서 **그림**을 고르면 돼요. 둘의 차이는 이래요.

| 옵션 | 원본 수정 시 | 붙여넣은 파일을 동료에게 전달하면 | 언제 쓰면 좋아요 |
| --- | --- | --- | --- |
| 그림 | 안 바뀜 (스냅샷) | 그대로 표시됨 | 확정된 자료 첨부 |
| 연결된 그림 | 자동 갱신 | 원본이 없으면 갱신 불가 | 숫자가 계속 바뀌는 보고서 |

## 방법 2 — 자주 쓴다면: 카메라 도구를 리본에 추가

표를 매주 옮긴다면 카메라 도구를 리본에 등록해 두는 편이 빨라요. 이 도구는 기본으로 숨어 있어서 직접 꺼내야 해요.

1. **파일 → 옵션 → 리본 사용자 지정**을 여세요.
2. 명령 선택을 **리본에 없는 명령**으로 바꾸고, 목록에서 **카메라**를 찾아 원하는 탭·그룹에 추가한 뒤 확인을 누르세요.

![Excel 옵션의 리본 사용자 지정 화면](/images/excel-linked-picture-6.png)
*그림 6. Excel 옵션에서 리본 사용자 지정 항목을 연 실측 화면. 카메라 추가 전 단계*

3. 이후에는 표 범위 선택 → `카메라` 클릭 → 그림을 놓을 위치를 클릭이면 끝이에요.

카메라로 넣은 그림도 원본과 연결이 살아 있어서 방법 1과 결과가 같아요. 차이는 버튼 하나로 단축되는 것뿐이에요.

## 안 될 때 — 실패 사례별 해결

- **붙여넣기 옵션에 연결된 그림이 없어요** — 대상이 메모장·웹 에디터처럼 그림 붙여넣기를 지원하지 않는 프로그램이거나, 복사 원본이 엑셀이 아니에요. 엑셀에서 다시 복사한 뒤 워드·파워포인트·엑셀로 옮겨 보세요.
- **원본을 고쳐도 그림이 안 바뀌어요** — 복사한 뒤 원본 통합문서의 이름을 바꾸거나 폴더를 옮기면 연결이 끊겨요. 원본 파일을 열어 둔 상태에서 다시 테스트하고, 끊긴 경우 원본을 제자리에 되돌리거나 다시 복사해 붙여넣어야 해요.
- **그림이 흐릿하게 보여요** — 원본 시트 배율이 100%가 아닐 때 흐릿해질 수 있어요. 보기 탭 배율을 100%로 맞추고 다시 복사해 보세요. [직접 확인 필요: 화면 배율·고DPI 환경에서의 영향]
- **표에 행을 추가하니 그림 범위를 벗어나요** — 연결은 선택한 범위에 고정돼요. 늘어날 표라면 여유 행을 포함해 선택하거나, 표를 다시 복사해 붙여넣어야 해요.
- **파일을 받은 동료 화면에서는 갱신이 안 돼요** — 연결은 원본이 같은 위치에 있을 때만 살아 있어요. 최종 제출본이라면 **그림**(스냅샷)으로 다시 붙여넣는 편이 안전해요.

## FAQ

### 구글 스프레드시트에도 연결된 그림이 있나요?

없어요. 이 기능은 데스크톱 엑셀 전용이에요. 스프레드시트에서는 윈도우 + Shift + S 화면 캡처로 대체하는 게 현실적이에요. [직접 확인 필요: 웹용 엑셀에서의 지원 여부]

### 그림과 연결된 그림의 차이가 뭐예요?

그림은 붙여넣은 순간의 스냅샷이고, 연결된 그림은 원본 범위를 참조하는 살아있는 개체예요. 원본이 자주 바뀌면 연결된 그림, 제출용 확정본이면 그림을 고르세요.

### PDF로 저장하거나 인쇄할 때도 나오나요?

나와요. 연결된 그림은 문서 안에서 이미지 개체로 표시되기 때문에 인쇄·PDF 변환 시에도 이미지 영역으로 처리돼요. 다만 PDF 변환 시 해상도는 원본 배율과 변환 설정에 따라 달라질 수 있어요.

### 원본 시트를 삭제하면 어떻게 되나요?

연결이 끊긴 마지막 화면이 남거나 오류가 표시될 수 있어요. 원본을 지우기 전에 **그림**(스냅샷)으로 다시 붙여넣어 고정하는 걸 권해요. [직접 확인 필요: 실제 동작]

## 정리

엑셀 표가 깨지는 문제는 "셀 복사"를 "그림 복사"로 바꾸는 것만으로 해결돼요. 기준은 하나예요. 숫자가 계속 바뀌는 문서는 연결된 그림, 확정본은 그림.

함께 보면 좋은 글 — 발행 준비 중: 엑셀 범위를 이미지 파일로 저장하는 법 · 윈도우 + Shift + S 캡처 활용법 · 파워포인트 표 자동 갱신하기. (발행되면 이 자리에 링크가 연결돼요.)
