# 무선 마우스로 갈아탄 일주일, 첫날 끊김을 해결한 방법

유선 마우스에서 2.4GHz 무선 마우스로 바꾼 첫날, 커서가 약 3초씩 멈췄습니다. 본체 앞면의 USB 3.0 포트에 있던 수신기를 뒷면의 USB 2.0 포트로 옮긴 뒤 7일 동안 같은 현상은 관찰되지 않았습니다.

포트 이동과 증상 소실은 이번 사용 환경에서 확인한 순서입니다. 다른 조건을 통제하지 않았기 때문에 USB 3.0 포트가 단독 원인이었다고 확정하지는 않습니다. 2026년 8월 30일부터 9월 5일까지 사용했고, 7일째 배터리 표시는 80%였습니다.

## 일주일 사용 결과는 어땠나

수신기를 본체 뒷면의 USB 2.0 포트로 옮긴 뒤 7일 동안 커서 멈춤 현상은 발생하지 않았습니다. 다만 포트 이동과 함께 증상이 사라진 사실만 확인했으므로, USB 3.0 포트가 직접 원인이었다고 단정하지 않습니다.

사용한 장비와 환경은 다음과 같습니다.

| 확인 항목 | 결과 |
|---|---|
| 사용 기간 | 2026-08-30 ~ 2026-09-05 |
| 교체 전 | 유선 마우스 |
| 교체 후 | 2.4GHz 무선 마우스 |
| 마우스 모델 | [직접 확인 필요: 마우스 제조사·모델명] |
| 컴퓨터 환경 | [직접 확인 필요: 운영체제·컴퓨터 모델·USB 포트 구성] |
| 첫날 문제 | 커서가 한 번에 약 3초씩 멈춤 |

| 조치 | USB 3.0 포트에서 USB 2.0 포트로 이동 |
| 조치 후 | 7일 동안 멈춤 현상 관찰되지 않음 |
| 7일째 배터리 표시 | 80% |

## 첫날 커서가 3초씩 멈췄습니다

첫날에는 본체 앞면의 USB 3.0 포트에 수신기를 꽂은 상태에서 커서가 약 3초씩 반복해서 멈췄습니다. 무선 마우스를 연결하면 바로 사용할 수 있을 것으로 생각했지만, 실제로는 연결 상태를 먼저 확인해야 했습니다.

당시에는 멈춤이 발생한 정확한 횟수를 기록하지 않았습니다. 따라서 반복적으로 끊겼다는 점은 말할 수 있지만, 하루 동안 몇 번 발생했는지는 [직접 확인 필요: 첫날 커서 멈춤 발생 횟수]입니다.

## USB 포트를 옮기자 문제가 사라졌습니다

수신기를 본체 앞면의 USB 3.0 포트에서 뒷면의 USB 2.0 포트로 옮긴 뒤 같은 멈춤 현상은 관찰되지 않았습니다. 이번 기록에서는 USB 3.0 포트에 연결한 상태와 커서 멈춤이 함께 나타났고, 포트를 바꾼 뒤 증상이 사라졌습니다.

다만 수신기 위치 외에 다른 조건을 함께 바꾸었는지는 따로 기록하지 않았습니다. 이번 결과만으로 USB 3.0 포트의 간섭이 확정된 원인이라고 보기는 어렵습니다.

2.4GHz 무선 마우스의 커서가 멈춘다면 다음 순서로 포트를 바꿔볼 수 있습니다.

1. 무선 마우스 수신기가 USB 3.0 포트에 연결되어 있는지 확인합니다.
2. 수신기를 본체 뒷면의 USB 2.0 포트로 옮깁니다.
3. 같은 작업을 하면서 커서 멈춤 현상이 다시 발생하는지 살펴봅니다.
4. 증상이 사라졌다면 바꾼 포트에서 계속 사용합니다.

이 순서는 이번 사용 환경에서 직접 확인한 방법입니다. 다른 컴퓨터나 다른 마우스에서도 같은 결과가 나오는지는 [직접 확인 필요: 다른 컴퓨터와 다른 2.4GHz 무선 마우스에서의 재현 여부]입니다.

## 7일째 배터리는 80%였습니다

7일째 배터리 표시는 80%였지만, 이 수치만으로 실제 배터리 지속 시간을 계산하지는 않았습니다. 배터리 표시가 실제 사용 시간과 정확히 일치하는지도 확인하지 않았습니다.

배터리 100%에서 방전될 때까지의 실제 사용 기간은 [테스트 필요: 배터리 100%에서 방전될 때까지의 실제 사용 기간]으로 남겨둡니다.

## 선 하나가 줄어드니 작업이 조금 편해졌습니다

무선 마우스로 바꾼 뒤 책상 위 연결선 하나가 사라져 마우스를 옮길 때 걸리는 부분이 줄었습니다. 큰 변화는 아니지만, 유선 마우스를 사용할 때보다 책상 위가 단순해진 점은 체감했습니다.

이번 교체에서 가장 오래 기억에 남은 것은 무선이라는 편리함보다 첫날의 끊김 문제였습니다. 포트를 옮긴 뒤 7일 동안 같은 현상이 나타나지 않아, 다음에 비슷한 장치를 연결할 때는 수신기 위치부터 확인할 생각입니다.

## 아직 확인하지 않은 것

이번 기록만으로는 USB 포트 외의 원인과 실제 배터리 지속 시간을 판단할 수 없습니다. 포트 이동 후에도 커서가 멈춘다면 아래 조건을 따로 나눠 확인해야 합니다.

- 배터리가 실제로 며칠 동안 지속되는지
- 블루투스 모드로 전환했을 때 지연이 발생하는지
- 다른 USB 포트나 다른 컴퓨터에서도 같은 현상이 생기는지
- 다른 2.4GHz 무선 장치가 있는 환경에서 증상이 반복되는지

이 내용은 직접 테스트하기 전까지 확정하지 않겠습니다.

## 한눈에 보기

이번 사용에서 확인한 조치는 수신기를 앞면 USB 3.0 포트에서 뒷면 USB 2.0 포트로 옮기는 일이었습니다.

| 상황 | 방법 | 주의할 점 |
|---|---|---|
| 커서가 약 3초씩 멈춤 | 수신기를 USB 3.0 포트에서 USB 2.0 포트로 이동 | USB 3.0 포트가 단독 원인인지는 확인 필요 |
| 7일째 배터리 표시가 궁금함 | 배터리 표시를 기록 | 실제 지속 기간과는 구분해야 함 |
| 책상 위 선을 줄이고 싶음 | 유선 마우스에서 2.4GHz 무선 마우스로 교체 | 블루투스 모드의 지연 여부는 미확인 |

이번 일주일의 기록은 수신기 포트를 바꾼 뒤 커서 멈춤이 사라졌다는 내용입니다. 2.4GHz 무선 마우스에서 비슷한 증상이 나타나면 수신기 위치를 USB 2.0 포트로 옮겨 보고, 다른 환경에서도 같은 결과가 나오는지는 별도로 확인해야 합니다.
