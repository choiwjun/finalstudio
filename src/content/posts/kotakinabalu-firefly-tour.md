## 투어 구성은 항목별로 비교합니다

뚜아이 원숭이와 선셋은 제목에 함께 적혀 있는지만 보지 말고, 일정표와 포함 항목에 각각 명시됐는지 확인해야 합니다.

검색 근거에는 반딧불투어와 함께 뚜아이 원숭이, 선셋, 맹그로브, 호텔 픽업, 공항 샌딩, 시티투어 등이 언급된 사례가 있습니다. 검색 제목과 설명만으로 특정 상품의 실제 구성이나 공통 조건을 확정할 수는 없습니다.

- 반딧불 중심으로 고른다면: 뚜아이 원숭이와 선셋이 포함되는지 각각 확인합니다.
- 원숭이·선셋 결합 일정이라면: 두 항목 모두 포함인지, 선택 옵션인지 구분합니다.
- 시티투어·호핑투어·마사지 등과 연결할 경우: 반딧불투어 단독 일정인지 결합 일정인지 확인합니다.

## 출발 시간대와 소요 시간은 시간표로 적습니다

출발 시간대와 소요 시간은 예약 안내에서 픽업 시각, 현장 일정, 호텔 복귀 시각을 한 줄로 기록해 비교합니다.

원자료에는 체크아웃 후 시내관광을 거쳐 반딧불투어로 이어지는 일정 사례가 있습니다. 이 사례를 모든 상품에 적용하지 말고, 실제 예약 일정에서 앞뒤 순서를 확인해야 합니다.

확인 순서는 다음과 같습니다.

1. 호텔 픽업 또는 집결 장소와 출발 시각을 적습니다.
2. 선셋과 반딧불 관찰의 순서를 확인합니다.
3. 총 소요 시간이 별도로 표시됐는지 확인합니다.
4. 복귀 시각과 다음 일정의 시작 시각을 비교합니다.

구체적인 출발 시각과 총 소요 시간은 제공된 원자료에 없으므로 다음처럼 남깁니다.

```text
호텔 픽업 시각: [직접 확인 필요: 예약 페이지의 출발 시각]
선셋 순서와 시각: [직접 확인 필요: 일정표]
반딧불 관찰 시각: [직접 확인 필요: 일정표]
호텔 복귀 시각: [직접 확인 필요: 복귀 예정 시각]
총 소요 시간: [직접 확인 필요: 상품 안내]
```

## 포함·불포함 사항을 나눠 봅니다

포함·불포함 사항은 투어 구성과 이동 서비스를 분리해 확인해야 합니다.

원자료에는 호텔 픽업, 공항 샌딩, 조인 투어가 함께 언급된 사례가 있습니다. 이 조건이 모든 상품에 적용되는지는 확인되지 않았습니다.

예약 안내에서 다음 항목을 각각 표시합니다.

1. 뚜아이 원숭이 포함 여부
2. 선셋 포함 여부
3. 맹그로브 또는 반딧불 일정 포함 여부
4. 호텔 픽업 포함 여부
5. 공항 샌딩 포함 여부
6. 조인 또는 단독 진행 여부
7. 불포함으로 표시된 항목 전체

확인되지 않은 항목은 빈칸으로 두지 말고 `[직접 확인 필요: 예약 안내의 포함·불포함 조건]`이라고 기록합니다. 특히 호텔 픽업과 공항 샌딩은 같은 이동 서비스로 묶지 말고 별도로 확인합니다.

## 예약 전에 어긋나기 쉬운 지점을 확인합니다

예약 전에는 상품 제목, 일정표, 포함 사항이 서로 일치하는지 대조해야 합니다.

- 제목에는 선셋이 있지만 일정표에 순서가 없는 경우  
  → 선셋이 실제 포함인지 선택 옵션인지 확인합니다.

- 뚜아이 원숭이와 맹그로브가 함께 언급되지만 포함 여부가 불분명한 경우  
  → 각 항목을 포함·불포함·확인 필요로 나눠 기록합니다.

- 호텔 픽업과 공항 샌딩을 하나의 이동 조건으로 이해한 경우  
  → 두 서비스를 별도 항목으로 다시 확인합니다.

- 체크아웃, 시티투어, 반딧불투어가 한 일정에 연결된 경우  
  → 앞 일정 종료 시각과 다음 픽업 시각을 비교합니다.

## 자주 묻는 질문

### 뚜아이 원숭이와 선셋은 항상 포함되나요?

제공된 원자료에는 두 항목을 함께 언급한 검색 결과가 있지만, 모든 상품에 포함된다는 내용은 확인되지 않았습니다. 예약 페이지에서 두 항목이 포함 사항으로 명시됐는지 [직접 확인 필요: 상품 안내]로 남겨 확인합니다.

### 코타키나발루 반딧불투어의 출발 시간과 총 소요 시간은 어떻게 확인하나요?

제공된 원자료에는 구체적인 출발 시각과 총 소요 시간이 없습니다. 호텔 픽업 시각, 일정 순서, 복귀 시각, 총 소요 시간을 상품 안내에서 직접 확인해야 합니다.

### 호텔 픽업과 공항 샌딩은 함께 제공되나요?

원자료의 한 검색 설명에서는 호텔 픽업과 공항 샌딩이 포함된 조인 투어로 소개합니다. 이 조건을 다른 상품에 적용하지 말고 두 서비스를 각각 확인합니다.

### 반딧불투어를 다른 여행 일정과 연결할 수 있나요?

원자료에는 시티투어, 호핑투어, 마사지, 선셋 등과 연결해 일정을 구성할 수 있다는 설명이 있습니다. 실제 예약 가능 여부와 이동 순서는 [직접 확인 필요: 판매자 안내]입니다.
