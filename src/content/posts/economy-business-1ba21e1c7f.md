## 주가 전망을 도구로 확인하는 4단계

검색 결과를 읽은 뒤에는 아래 순서로 확인 메모를 작성하면 됩니다.

1. **블로그 제목에서 주장만 추출합니다.**  
   `수주`, `실적`, `테마`, `반등`, `목표가격`처럼 주장을 유형별로 나눕니다. 제목에 나온 표현을 사실로 옮겨 적지 말고, 확인 질문으로 바꿉니다.

2. **검색 추세의 조건과 값을 따로 기록합니다.**  
   이번 원자료의 그룹은 `주가 전망`이며, 기준일은 2026년 9월 10일입니다. 최신 상대 지표는 56.47058이고 최대 상대 지표는 100입니다. [직접 확인 필요: API 요청 기간·기기·연령·성별·원본 응답]

3. **국내 기업 관련 사실은 공식 공시에서 확인합니다.**  
   DART에서는 공시 원문, 사업보고서, 주요 재무정보 등을 조회할 수 있습니다. [전자공시 OPENDART 공식 소개](https://opendart.fss.or.kr/intro/main.do)에서 이용 범위와 개발 안내를 확인할 수 있습니다.

4. **확인 결과를 세 줄로 정리합니다.**

   ```text
   확인한 사실:
   아직 확인하지 않은 주장:
   다음에 확인할 공식 자료와 기준일:
   ```

   이 메모를 작성하면 검색 관심과 기업 사실, 개인의 다음 판단 기준이 한 문서 안에서 섞이지 않습니다.

## 검색 결과가 헷갈릴 때 확인할 세 가지

### 블로그 제목을 사실로 읽는 경우

검색 제목은 관심을 끌기 위한 요약일 수 있으므로, 제목만으로 수주·실적·목표가격을 확정해서는 안 됩니다. 원문에서 숫자의 출처와 기준일을 확인하고, 출처가 없으면 `[직접 확인 필요: 주장 근거]`로 남깁니다.

### 상대 지표를 절대 검색량으로 바꾸는 경우

56.47058은 특정 조건 안에서 계산된 상대값입니다. 절대 검색량이나 전체 이용자 중 비율로 표현하지 않고, 기간과 검색 조건을 함께 기록해야 합니다.

### 같은 목표가격이 반복된다고 독립 근거로 보는 경우

여러 블로그가 같은 목표가격을 언급해도 하나의 자료를 반복 인용했을 수 있습니다. 목표가격을 확인하려면 실제 증권사 리포트의 발행일, 제시 조건, 원문 존재 여부를 별도로 확인해야 합니다. [직접 확인 필요: 목표가격 원문과 발행 주체]

## FAQ

### 검색 추세 56.47058은 인기가 56%라는 뜻인가요?

아닙니다. 56.47058은 같은 조건 안에서 최고값 100과 비교한 상대 지표입니다. 절대 검색량이나 주가 상승률로 해석하면 안 됩니다.

### 주가 전망 블로그가 여러 개면 내용이 더 믿을 만한가요?

반드시 그렇지는 않습니다. 같은 자료를 반복했을 가능성이 있으므로, 각 글의 원출처와 기준일을 확인해야 합니다.

### 초보자는 주가 전망을 볼 때 무엇부터 확인해야 하나요?

먼저 글의 주장과 검색 추세를 분리합니다. 그다음 기업 공시에서 실적·계약·사업 내용을 확인합니다. 확인되지 않은 부분은 판단 근거에서 제외합니다.

### 검색량이 오르면 주가도 오르나요?

검색 관심과 주가 방향은 같은 지표가 아닙니다. 검색량은 관심 변화를 보여줄 뿐이며, 주가 방향을 결정하는 공식 신호로 사용할 수 없습니다.
