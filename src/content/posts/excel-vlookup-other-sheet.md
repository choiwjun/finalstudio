주문서에 상품 코드만 입력하고 상품명과 가격을 자동으로 채우고 싶다면 `VLOOKUP`을 사용하면 됩니다. 핵심은 어렵지 않습니다. **기준 코드가 있는 셀, 조회할 표의 범위, 가져올 열 번호, 정확히 일치할지 여부** 네 가지만 지정하면 됩니다.

이 글에서는 `주문서` 시트의 상품 코드를 기준으로 `상품목록` 시트에서 상품명과 가격을 가져옵니다. 아래 수식을 그대로 입력하면 같은 결과를 확인할 수 있습니다.

## 완성 수식부터 확인하기

`주문서` 시트가 다음처럼 구성되어 있다고 가정합니다.

| A열 | B열 | C열 |
| --- | --- | --- |
| 상품 코드 | 상품명 | 가격 |
| P001 | 노트 | 3000 |
| P002 | 볼펜 | 1500 |

`A2`의 상품 코드로 `상품목록` 시트를 조회해 상품명을 가져오려면 `B2`에 입력합니다.

```text
=VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
```

가격을 가져올 때는 반환 열 번호만 `3`으로 바꿉니다.

```text
=VLOOKUP(A2,상품목록!$A$2:$C$100,3,FALSE)
```

여기서 `2`와 `3`은 엑셀 전체 열 번호가 아니라 `상품목록!$A$2:$C$100` 범위 안에서의 순서입니다. `FALSE`는 상품 코드가 완전히 일치할 때만 결과를 반환하라는 뜻입니다. 상품 코드처럼 오타 하나가 다른 상품으로 연결될 수 있는 값에는 `FALSE`를 명시하는 편이 안전합니다.

## 1. 조회용 표를 두 시트에 나누기

먼저 두 시트를 준비합니다.

- `주문서`: 사용자가 상품 코드를 입력하고 결과를 확인하는 시트
- `상품목록`: 상품 코드, 상품명, 가격을 보관하는 시트

`상품목록`의 조회 범위는 반드시 상품 코드 열부터 시작해야 합니다. VLOOKUP은 지정한 범위의 **첫 번째 열**에서만 기준값을 찾기 때문입니다.

![실제 Excel에서 준비한 상품목록 시트](/images/excel-vlookup-products.png)
*그림 1. Microsoft 365 Excel에서 조회 원본으로 준비한 상품목록 범위*

상품 코드가 `상품목록`의 B열에 있는데 범위를 `A:C`로 잡으면 원하는 결과를 얻을 수 없습니다. 기준 코드가 B열에 있다면 범위도 B열부터 시작해야 합니다.

## 2. 상품명과 가격을 연결하기

이제 `주문서` 시트에서 수식을 입력합니다.

1. 상품명을 표시할 `B2`를 선택합니다.
2. 아래 수식을 입력하고 `Enter`를 누릅니다.

   ```text
   =VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
   ```

3. `B2`에 `노트`가 표시되는지 확인합니다.
4. 가격을 표시할 `C2`에는 열 번호를 `3`으로 바꿔 입력합니다.

   ```text
   =VLOOKUP(A2,상품목록!$A$2:$C$100,3,FALSE)
   ```

5. `B2:C2`를 선택한 뒤 채우기 핸들을 아래로 끌어 `P002`에도 수식을 복사합니다.

![실제 Excel에서 VLOOKUP 결과가 계산된 주문서 시트](/images/excel-vlookup-orders.png)
*그림 2. 상품 코드에 따라 상품명과 가격이 계산된 주문서 범위*

이번 예제는 Microsoft 365 Excel 16.0(Build 20326)에서 직접 계산했습니다. `P001`은 `노트·3000`, `P002`는 `볼펜·1500`으로 표시됐고, 통합 문서를 저장한 뒤 다시 열어도 결과가 유지됐습니다.

## 3. 수식을 복사할 때 범위를 고정하기

수식을 아래로 복사하면 `A2`는 `A3`, `A4`처럼 행에 맞춰 바뀌어야 합니다. 반면 상품목록 범위는 계속 같은 곳을 가리켜야 합니다.

그래서 조회값은 `A2`로 두고, 표 범위에는 `$`를 붙입니다.

```text
=VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
```

`$A$2:$C$100`에서 `$`를 빼면 아래 행으로 복사할 때 범위가 함께 내려갑니다. 첫 행에서는 맞아도 다음 행부터 다른 범위를 읽어 `#N/A`나 엉뚱한 값이 나올 수 있습니다.

## 4. 결과가 이상할 때 확인할 세 가지

### `#N/A`가 표시되는 경우

조회 범위의 첫 열에서 기준 코드를 찾지 못했다는 뜻입니다. 코드의 오타, 앞뒤 공백, 숫자와 텍스트 형식 차이를 먼저 확인합니다. 실제 테스트에서도 존재하지 않는 `P999`를 조회했을 때 `#N/A`가 표시됐습니다.

조회 실패를 빈칸으로 숨겨야 한다면 다음처럼 `IFERROR`를 붙일 수 있습니다.

```text
=IFERROR(VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE),"")
```

다만 오류를 숨기면 잘못 입력한 상품 코드를 놓칠 수 있으므로, 검수용 시트에서는 `#N/A`를 그대로 보여주는 편이 낫습니다.

### 엉뚱한 값이 표시되는 경우

마지막 인수를 생략하거나 `TRUE`로 입력하면 근사 일치가 사용될 수 있습니다. 이 방식은 첫 열이 정렬되어 있다는 전제가 필요하고, 상품 코드 조회에서는 예상하지 못한 값이 반환될 수 있습니다.

상품 코드처럼 정확히 일치해야 하는 값에는 항상 다음처럼 `FALSE`를 적습니다.

```text
=VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
```

### `#REF!`가 표시되는 경우

반환 열 번호가 조회 범위를 벗어난 경우입니다. `A:C`는 세 열로 이루어져 있으므로 열 번호에 `4`를 넣으면 안 됩니다. 실제 테스트에서도 `4`를 입력했을 때 `#REF!`가 표시됐습니다.

시트 이름에 공백이 있다면 작은따옴표로 감쌉니다.

```text
=VLOOKUP(A2,'상품 목록'!$A$2:$C$100,2,FALSE)
```

## 5. VLOOKUP을 계속 쓸까, XLOOKUP으로 바꿀까?

VLOOKUP은 오래된 Excel 버전에서도 사용할 수 있고 기본 조회에는 충분합니다. 다만 기준 열의 왼쪽 값을 가져오거나, 열을 추가해도 수식을 덜 흔들리게 관리하려면 XLOOKUP이 더 편합니다.

| 상황 | 추천 | 이유 |
| --- | --- | --- |
| Excel 2016·2019와 파일을 공유해야 함 | VLOOKUP | 호환성이 좋음 |
| Microsoft 365 또는 Excel 2021 이상을 사용함 | XLOOKUP 검토 | 조회 범위와 반환 범위를 따로 지정할 수 있음 |
| 기준 열의 왼쪽 값을 가져와야 함 | XLOOKUP 또는 INDEX/MATCH | VLOOKUP은 기본적으로 오른쪽 값만 반환함 |
| 간단한 상품 코드 조회가 필요함 | VLOOKUP | 수식이 짧고 기존 파일과 호환하기 쉬움 |

Microsoft도 XLOOKUP을 VLOOKUP의 개선된 함수로 안내하지만, 다른 버전의 Excel과 파일을 주고받는다면 먼저 사용 환경을 확인해야 합니다. [Microsoft 조회 함수 안내](https://support.microsoft.com/ko-kr/excel/look-up-values-with-vlookup-index-or-match)

## 한눈에 점검하기

- 기준값은 조회 범위의 첫 번째 열에 있는가?
- 상품명은 범위 안에서 두 번째 열, 가격은 세 번째 열인가?
- 정확한 코드 조회에 `FALSE`를 넣었는가?
- 아래로 복사할 범위에 `$`를 붙였는가?
- 코드의 앞뒤 공백과 숫자·텍스트 형식이 같은가?
- 사용 중인 Excel 버전에서 XLOOKUP으로 바꿔도 되는가?

결국 기억할 것은 하나입니다. `VLOOKUP(찾을 값, 찾을 범위, 가져올 열 번호, FALSE)` 형식으로 작성하고, 복사할 범위만 절대참조로 고정하면 됩니다.
