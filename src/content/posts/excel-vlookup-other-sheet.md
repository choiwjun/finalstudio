슬러그 제안: `excel-vlookup-other-sheet`

엑셀 VLOOKUP으로 다른 시트 데이터를 가져오려면 조회할 셀과 다른 시트의 표 범위를 수식으로 연결하면 돼요. 예를 들어 주문서에 상품 코드만 입력하고, 상품목록 시트에서 상품명과 가격을 자동으로 불러올 수 있어요.

이 글에서는 같은 통합 문서 안에 있는 `주문서` 시트와 `상품목록` 시트를 연결하는 기본 예제를 설명해요.

## 핵심 요약

> **엑셀 VLOOKUP 핵심**
>
> `주문서` 시트의 상품 코드가 `A2`에 있고, `상품목록` 시트의 A열부터 C열까지 조회한다면 다음 수식을 사용해요.
>
> 상품명:
>
> ```excel
> =VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
> ```
>
> 가격:
>
> ```excel
> =VLOOKUP(A2,상품목록!$A$2:$C$100,3,FALSE)
> ```
>
> `FALSE`는 상품 코드가 정확히 일치할 때만 찾는다는 뜻이에요. `$A$2:$C$100`은 수식을 아래로 복사해도 조회 범위가 바뀌지 않도록 고정한 범위예요.

VLOOKUP은 지정한 표의 첫 번째 열에서 기준값을 찾고, 같은 행의 오른쪽 값을 반환하는 함수예요. 마이크로소프트 공식 문서도 조회값이 지정한 범위의 첫 번째 열에 있어야 한다고 안내해요. [마이크로소프트 VLOOKUP 공식 문서](https://support.microsoft.com/ko-kr/excel/functions/vlookup-function)

| 수식 부분 | 의미 |
|---|---|
| `A2` | 찾을 상품 코드 |
| `상품목록!` | 상품목록 시트에서 찾는다는 뜻 |
| `$A$2:$C$100` | 검색할 표의 범위 |
| `2` | 범위의 두 번째 열에서 결과를 가져옴 |
| `FALSE` | 상품 코드가 정확히 일치할 때만 찾음 |

## 다른 시트에서 조회할 표를 준비해요

다른 시트 조회는 기준값을 입력하는 주문서와 기준값·결과값을 보관하는 상품목록을 나누면 시작해요.

`주문서` 시트에는 사용자가 상품 코드를 입력해요.

| A열 | B열 | C열 |
|---|---|---|
| 상품 코드 | 상품명 | 가격 |
| P001 |  |  |
| P002 |  |  |

`상품목록` 시트에는 상품 코드, 상품명, 가격을 정리해요.

| A열 | B열 | C열 |
|---|---|---|
| 상품 코드 | 상품명 | 가격 |
| P001 | 노트 | 3000 |
| P002 | 볼펜 | 1500 |

VLOOKUP은 조회 범위의 첫 번째 열에서 기준값을 찾아요. 따라서 상품 코드가 `상품목록` 범위의 A열에 있어야 상품명이나 가격을 가져올 수 있어요.

상품 코드가 중복되면 VLOOKUP은 위에서부터 처음 일치한 행의 값을 반환해요. 상품 코드가 고유한지 먼저 확인하는 것도 필요해요.

[스크린샷 필요: `주문서` 시트와 `상품목록` 시트에 상품 코드, 상품명, 가격이 입력된 화면]

## VLOOKUP으로 다른 시트의 상품명을 가져와요

상품명은 `주문서` 시트의 B2 셀에서 다른 시트의 상품표를 조회하면 가져올 수 있어요.

1. `주문서` 시트에서 상품명을 표시할 `B2` 셀을 선택해요.
2. 다음 수식을 입력해요.

```excel
=VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
```

3. `Enter` 키를 눌러요.
4. 예시 데이터라면 `B2`에 `노트`가 표시돼요.
5. B2 셀의 오른쪽 아래 채우기 핸들을 아래로 끌어 수식을 복사해요.

채우기 핸들은 선택한 셀 오른쪽 아래 모서리에 있는 작은 표시로, 수식을 인접한 셀에 복사하는 기능이에요.

이 수식은 `주문서` 시트의 `A2` 상품 코드를 `상품목록` 시트의 A열에서 찾아요. 일치하는 행의 두 번째 열인 상품명을 `주문서` 시트의 B2에 표시해요.

가격은 범위에서 세 번째 열에 있으므로 열 번호만 `3`으로 바꾸면 돼요.

```excel
=VLOOKUP(A2,상품목록!$A$2:$C$100,3,FALSE)
```

한국어 Excel UI에서 함수를 찾아 입력하려면 `수식` 탭 → `함수 라이브러리` 그룹 → `함수 삽입`을 선택한 뒤 `VLOOKUP`을 검색하면 돼요. 수식 구조를 익히는 목적이라면 함수 마법사 대신 수식을 직접 입력해도 돼요.

[스크린샷 필요: `주문서` 시트의 B2 셀에 VLOOKUP 수식을 입력한 뒤 상품명이 표시된 화면]

## VLOOKUP 수식의 네 가지 값을 이해해요

VLOOKUP 수식은 조회값, 표 범위, 열 번호, 일치 방식 네 가지 값으로 구성돼요.

| 구성 요소 | 초보자용 설명 | 예시 |
|---|---|---|
| 조회값 | 다른 표에서 찾을 기준값 | `A2` |
| 표 범위 | 기준값과 결과값이 함께 있는 범위 | `상품목록!$A$2:$C$100` |
| 열 번호 | 범위 안에서 결과를 가져올 열의 순서 | `2` 또는 `3` |
| 일치 방식 | 정확히 찾을지 가까운 값을 찾을지 결정 | `FALSE` |

`VLOOKUP`은 지정한 범위의 첫 열에서 조회값을 찾고 같은 행의 오른쪽 값을 반환하는 함수예요.

`FALSE`는 조회값과 완전히 같은 값만 반환하도록 지정하는 인수예요. 상품 코드처럼 오타나 중복을 엄격하게 확인해야 하는 값에는 `FALSE`를 사용하는 편이 안전해요.

열 번호는 엑셀 전체 열 번호가 아니라 지정한 범위 안에서 계산해요. `A:C` 범위에서 B열의 값을 가져오면 `2`, C열의 값을 가져오면 `3`이에요.

`$` 기호는 수식을 복사해도 조회 범위가 움직이지 않도록 셀 주소를 고정하는 역할을 해요. 따라서 `$A$2:$C$100`처럼 범위를 고정하면 아래 행에서도 같은 상품표를 조회할 수 있어요.

시트 이름에 띄어쓰기가 있다면 시트 이름을 작은따옴표로 감싸야 해요.

```excel
=VLOOKUP(A2,'상품 목록'!$A$2:$C$100,2,FALSE)
```

## VLOOKUP이 안 될 때 확인해요

VLOOKUP 오류는 조회값의 형식, 범위의 첫 열, 열 번호, 일치 방식을 순서대로 확인하면 원인을 좁힐 수 있어요.

### `#N/A` 오류가 나와요

`#N/A`는 조회값과 정확히 일치하는 값을 찾지 못했다는 뜻이에요.

다음 항목을 확인해요.

- 주문서와 상품목록의 상품 코드에 오타가 없는지 확인해요.
- 코드 앞뒤에 불필요한 공백이 없는지 확인해요.
- 한쪽은 숫자이고 다른 쪽은 문자로 저장되어 있지 않은지 확인해요.
- `001`과 숫자 `1`을 서로 다른 코드로 사용하고 있지 않은지 확인해요.
- 상품 코드가 `상품목록` 범위의 첫 번째 열에 있는지 확인해요.

조회에 실패했을 때 오류 대신 빈칸으로 표시하려면 `IFERROR`를 함께 사용할 수 있어요.

```excel
=IFERROR(VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE),"")
```

`IFERROR`는 수식에서 오류가 발생할 때 지정한 대체 값을 표시하는 함수예요. 위 수식은 조회 결과가 없을 때 `#N/A` 대신 빈칸을 표시해요.

다만 오류를 숨기면 잘못된 상품 코드가 입력된 사실을 놓칠 수 있으므로, 검토가 끝난 뒤 사용하는 편이 좋아요.

### 엉뚱한 값이 표시돼요

마지막 인수를 생략하거나 `TRUE`로 입력하면 VLOOKUP이 근사값을 찾을 수 있어요. 근사값 조회는 첫 번째 열이 오름차순으로 정렬되어 있어야 하므로 상품 코드 조회에는 적합하지 않을 수 있어요.

상품 코드처럼 정확한 값을 찾을 때는 아래처럼 `FALSE`를 입력해요.

```excel
=VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
```

### `#REF!` 오류가 나와요

`#REF!`는 가져올 열 번호가 지정한 범위를 벗어났을 때 발생할 수 있어요.

예를 들어 `A:C` 범위에는 세 개의 열만 있으므로 열 번호에 `4`를 입력하면 오류가 나요. 가격이 C열에 있다면 열 번호는 `3`이어야 해요.

```excel
=VLOOKUP(A2,상품목록!$A$2:$C$100,3,FALSE)
```

### 수식을 아래로 복사하면 조회 범위가 바뀌어요

수식을 아래로 복사했을 때 조회 범위가 `$A$3:$C$101`처럼 바뀌면 `$` 기호가 빠진 상태일 수 있어요.

조회값인 `A2`는 행마다 바뀌어야 하므로 그대로 두고, 상품목록 범위만 아래처럼 고정해요.

```excel
=VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)
```

### 시트 이름에 띄어쓰기가 있어요

시트 이름이 `상품 목록`처럼 띄어쓰기를 포함하면 작은따옴표를 사용해야 해요.

```excel
=VLOOKUP(A2,'상품 목록'!$A$2:$C$100,2,FALSE)
```

시트 이름의 철자와 띄어쓰기가 실제 탭 이름과 같은지도 확인해요.

## 조회 결과가 빈칸인데 0으로 표시돼요

VLOOKUP이 원본의 빈 셀을 반환하면 Excel에서 `0`으로 보일 수 있어요. `IFERROR`는 조회 실패 같은 오류를 빈칸으로 바꾸지만, 오류가 아닌 `0`은 그대로 표시해요.

조회에 실패했을 때만 빈칸으로 표시하려면 다음 수식을 사용해요.

```excel
=IFERROR(VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE),"")
```

상품명처럼 숫자 `0`이 유효한 결과가 아닌 열에서 원본 빈 셀도 빈칸으로 표시하려면 다음 수식을 사용할 수 있어요.

```excel
=IFERROR(IF(VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)=0,"",VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)),"")
```

이 수식은 상품명이 비어 있거나 조회에 실패하면 빈칸을 표시해요. 가격처럼 실제 `0`이 유효한 값일 수 있는 열에는 이 방식을 적용하기 전에 업무 규칙을 확인해야 해요.

## 발행 전 1분 점검표

- [ ] 조회값이 상품목록 범위의 첫 번째 열에 있어요.
- [ ] 상품 코드의 숫자·문자 형식이 양쪽에서 같아요.
- [ ] 상품 코드에 불필요한 공백이 없어요.
- [ ] 상품명은 열 번호 `2`를 사용했어요.
- [ ] 가격은 열 번호 `3`을 사용했어요.
- [ ] 정확한 조회에는 `FALSE`를 입력했어요.
- [ ] 수식을 복사할 범위에 `$`를 붙였어요.
- [ ] 시트 이름에 띄어쓰기가 있으면 작은따옴표를 사용했어요.
- [ ] 조회 실패와 원본 빈 셀을 구분해 처리했어요.
- [ ] 실제 Excel 버전에서 수식과 결과를 확인했어요.

## 자주 묻는 질문

### 다른 엑셀 파일의 시트에서도 데이터를 가져올 수 있나요?

다른 엑셀 파일의 범위도 VLOOKUP으로 연결할 수 있어요. 다만 외부 파일 경로와 파일명이 수식에 포함되므로 파일을 이동하거나 이름을 바꾸면 연결을 다시 확인해야 해요.

처음 연습할 때는 같은 통합 문서 안에서 `주문서`와 `상품목록` 시트를 연결하는 방법부터 익히는 편이 쉬워요.

### VLOOKUP으로 왼쪽 열의 값을 가져올 수 있나요?

기본 VLOOKUP은 조회 범위의 첫 번째 열에서 값을 찾고 오른쪽 열의 결과를 반환해요. 조회값의 왼쪽에 있는 데이터를 가져오려면 XLOOKUP 또는 INDEX와 MATCH 조합을 검토할 수 있어요.

마이크로소프트는 XLOOKUP을 VLOOKUP의 개선된 함수로 소개해요. [마이크로소프트 조회 함수 안내](https://support.microsoft.com/ko-kr/excel/look-up-values-with-vlookup-index-or-match)

### 상품 코드 대신 상품명으로 가격을 가져올 수 있나요?

상품명으로 가격을 찾으려면 상품명이 조회 범위의 첫 번째 열에 있어야 해요. 예를 들어 상품명이 A열이고 가격이 B열이면 다음처럼 열 번호 `2`를 사용해요.

```excel
=VLOOKUP(A2,상품목록!$A$2:$B$100,2,FALSE)
```

상품명이 중복되면 처음 일치한 상품의 가격이 반환될 수 있어요. 따라서 상품명보다 고유한 상품 코드를 기준값으로 사용하는 편이 안전해요.

### 조회 결과가 빈칸인데 0으로 표시돼요?

조회된 결과 셀이 비어 있으면 Excel에서 `0`으로 표시될 수 있어요. 원본 표의 결과 셀에 실제 값이 있는지 먼저 확인해요.

조회에 실패한 경우만 빈칸으로 표시하려면 다음처럼 `IFERROR`를 사용해요.

```excel
=IFERROR(VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE),"")
```

원본 셀이 비어 있을 때도 빈칸으로 표시하려면 앞에서 설명한 `IF` 조합을 사용해요. 오류를 무조건 숨기지 말고 발행 전 처리 기준을 확인해야 해요.

| 상황 | 방법 | 주의 |
|---|---|---|
| 다른 시트의 상품명을 가져올 때 | `=VLOOKUP(A2,상품목록!$A$2:$C$100,2,FALSE)` | 상품 코드가 범위의 첫 열이어야 해요 |
| 다른 시트의 가격을 가져올 때 | 열 번호를 `3`으로 변경해요 | 열 번호는 지정한 범위 안에서 계산해요 |
| 시트 이름에 띄어쓰기가 있을 때 | `'상품 목록'!`처럼 작은따옴표를 사용해요 | 시트 이름을 정확히 입력해요 |
| 수식을 아래로 복사할 때 | `$A$2:$C$100`처럼 범위를 고정해요 | `$`가 없으면 범위가 움직일 수 있어요 |
| `#N/A`가 표시될 때 | 코드 오타·공백·자료 형식을 확인해요 | 숫자와 문자의 형식도 비교해요 |
| 조회 실패를 빈칸으로 표시할 때 | `IFERROR`로 대체 값을 지정해요 | 오류를 숨기면 원인 확인이 어려워요 |
| 원본 빈 셀이 0으로 표시될 때 | `IF` 조합으로 빈 결과를 처리해요 | 가격의 실제 0 값과 구분해야 해요 |

엑셀 VLOOKUP으로 다른 시트 데이터를 가져올 때는 `시트이름!범위` 형식을 기억하면 돼요. 상품 코드처럼 정확히 일치해야 하는 값을 조회한다면 `FALSE`를 입력하고, 수식을 복사할 때는 조회 범위에 `$`를 붙여요.

### 이어서 연결할 내부 링크 후보

- `엑셀 XLOOKUP 다른 시트에서 값 가져오는 방법`  
  왼쪽 열 조회와 동적 범위 사용법으로 이어지는 후속 글이에요.  
  슬러그: `excel-xlookup-other-sheet`

- `엑셀 IFERROR로 VLOOKUP 오류 대신 빈칸 표시하기`  
  `#N/A`, 원본 빈 셀, 오류 숨김 여부를 구분하는 후속 글 후보예요.  
  슬러그: `excel-iferror-vlookup-blank`
