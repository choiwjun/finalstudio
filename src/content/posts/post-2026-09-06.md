PC 브라우저 북마크가 중복됐다면, 북마크 관리자에서 이름순으로 정렬한 뒤 URL이 같은 항목만 비교해 하나씩 삭제합니다. 삭제하기 전에는 북마크를 HTML 파일로 백업해 실수에 대비해야 합니다.

이 글은 Chrome을 중심으로 설명합니다. Edge에서는 북마크를 즐겨찾기라고 부르며, 비슷한 관리 화면에서 같은 방식으로 정리합니다.

## 핵심 요약

가장 안전한 순서는 **백업 → 폴더별 정렬 → URL 비교 → 중복 항목 삭제 → 남은 링크 확인**입니다.

| 순서 | 할 일 | 판단 기준 |
| --- | --- | --- |
| 1 | 북마크 HTML 백업 | 삭제 전 원본을 보관합니다. |
| 2 | 북마크 관리자 열기 | 북마크 폴더를 하나씩 확인합니다. |
| 3 | 이름순 정렬 | 같은 이름의 항목을 가까이 모읍니다. |
| 4 | URL 비교 | URL이 완전히 같은지 확인합니다. |
| 5 | 하나만 삭제 | 자주 쓰는 폴더의 항목을 남깁니다. |
| 6 | 남은 북마크 열기 | 링크가 정상적으로 열리는지 확인합니다. |

## 이름보다 URL을 먼저 비교해야 합니다

북마크 중복 여부는 이름이 아니라 URL이 같은지를 기준으로 판단합니다. 이름이 같아도 URL이 다르면 서로 다른 페이지일 수 있습니다.

다음 표에서 URL이 완전히 같은 두 항목은 하나만 남겨도 됩니다.

| 북마크 이름 | 저장 위치 | URL | 처리 |
| --- | --- | --- | --- |
| 도움말 | 북마크바 | `https://example.com/help` | 유지 |
| 도움말 | 기타 북마크 | `https://example.com/help` | 삭제 후보 |
| 도움말 | 북마크바 | `https://example.com/help/setup` | 별도 유지 |

`/help`와 `/help/setup`처럼 주소 뒤의 경로가 다르면 다른 페이지입니다. `?source=mail`처럼 물음표 뒤의 값이 붙은 주소도 바로 삭제하지 마세요. 로그인 상태, 검색 조건, 추적 정보가 포함됐을 수 있으므로 두 페이지를 열어 확인합니다.

이름순 정렬은 중복 후보를 찾는 단계입니다. 최종 삭제 여부는 반드시 URL을 비교해 결정합니다.

## 삭제 전 북마크를 HTML로 백업하기

Chrome에서는 북마크 관리자에서 북마크를 HTML 파일로 내보낼 수 있습니다. Google은 HTML 파일을 사용해 다른 브라우저로 북마크를 옮길 수 있다고 안내합니다. [Chrome 북마크 내보내기 공식 안내](https://support.google.com/chrome/answer/96816?hl=ko)

1. Chrome 오른쪽 상단의 더보기 버튼을 선택합니다.
2. `북마크 및 목록`에서 `북마크 관리자`를 엽니다.
3. 북마크 관리자 상단의 더보기 버튼을 선택합니다.
4. `북마크 내보내기`를 선택합니다.
5. 파일 이름을 확인하고 찾기 쉬운 폴더에 저장합니다.

파일 이름은 `bookmarks-before-cleanup-2026-09-06.html`처럼 정리 전 상태가 드러나게 지정합니다.

[테스트 필요: Windows PC의 Chrome 한국어 화면에서 메뉴 이름과 HTML 파일 저장 위치 확인]

## Chrome에서 중복 북마크 정리하기

Chrome에서는 북마크 관리자를 열어 폴더별로 이름을 정렬한 다음, 같은 URL을 가진 항목을 삭제합니다. Chrome 공식 도움말에는 북마크 관리자에서 정렬·수정·삭제하는 방법이 나와 있습니다. [Chrome 북마크 관리 공식 안내](https://support.google.com/chrome/answer/188842?co=GENIE.Platform%3DDesktop&hl=ko)

1. Chrome 오른쪽 상단의 더보기 버튼을 선택합니다.
2. `북마크 및 목록`에서 `북마크 관리자`를 선택합니다.
3. 왼쪽 목록에서 `북마크바` 폴더를 엽니다.
4. 북마크 관리자 상단의 더보기 버튼에서 `이름순 정렬`을 선택합니다.
5. 이름이 같은 북마크를 찾아 각각의 더보기 버튼에서 `수정`을 선택합니다.
6. 두 항목의 URL이 완전히 같은지 비교합니다.
7. 하나만 남기고 나머지 항목에서 `삭제`를 선택합니다.
8. 남겨 둔 북마크를 열어 원하는 페이지가 표시되는지 확인합니다.
9. `기타 북마크`와 그 안의 하위 폴더도 같은 방법으로 확인합니다.

자주 사용하는 링크라면 `북마크바`에 남기는 편이 찾기 쉽습니다. 저장 위치가 중요하지 않다면 이름이 더 명확한 항목을 남겨도 됩니다.

Chrome은 북마크를 삭제하면 다시 복구할 수 없다고 안내합니다. 삭제 전에 HTML 백업 파일이 제대로 저장됐는지 확인합니다.

## Chrome이 아니거나 정리가 안 될 때

Chrome이 아닌 브라우저도 북마크 관리자 또는 즐겨찾기 관리 화면에서 정렬·비교·삭제 순서를 적용하면 됩니다.

### Microsoft Edge를 사용하는 경우

Edge에서는 북마크를 `즐겨찾기`라고 부릅니다. `설정 및 기타` 메뉴에서 `즐겨찾기` 관리 화면을 열고, 즐겨찾기 페이지에서 마우스 오른쪽 버튼을 눌러 `이름별로 정렬`을 선택합니다.

같은 이름의 항목을 열어 URL을 비교합니다. Edge의 폴더 구조가 여러 단계라면 즐겨찾기 모음과 하위 폴더를 각각 확인해야 합니다.

[직접 확인 필요: 사용 중인 Microsoft Edge 버전의 한국어 메뉴 이름과 삭제 후 동기화 결과]

### 같은 이름인데 중복이 아닌 경우

같은 이름의 북마크라도 URL이 다르면 다른 페이지일 수 있습니다. 페이지 제목을 구분하기 어렵다면 북마크 이름 뒤에 `- 설정`, `- 안내`처럼 용도를 덧붙입니다.

### 중복 항목이 계속 보이는 경우

서로 다른 폴더에 중복 항목이 있으면 한 폴더만 정렬해서는 찾을 수 없습니다. 북마크바, 기타 북마크, 가져온 북마크 폴더와 하위 폴더를 차례로 확인합니다.

### 다른 기기에서 북마크가 함께 사라진 경우

Chrome에 Google 계정으로 로그인하면 북마크가 여러 기기에서 동기화될 수 있습니다. PC에서 삭제한 북마크도 다른 기기에 반영될 수 있으므로, 삭제 전 현재 Chrome 프로필과 동기화 상태를 확인합니다.

## 자주 묻는 질문

### 북마크 이름이 다르면 중복이 아닌가요?

이름이 달라도 URL이 같으면 같은 페이지를 저장한 중복 항목일 수 있습니다. 이름순 정렬은 후보를 찾는 데만 사용하고, URL을 직접 비교해야 합니다.

### Chrome에서 중복 북마크를 한 번에 지울 수 있나요?

초보자라면 자동 삭제보다 폴더별로 정렬한 뒤 URL을 비교하는 방법이 안전합니다. 같은 사이트의 다른 페이지까지 함께 삭제하는 실수를 줄일 수 있습니다.

### 실수로 북마크를 삭제하면 어떻게 하나요?

삭제 전에 저장한 HTML 백업 파일이 있다면 북마크를 다시 가져올 수 있습니다. 기존 북마크가 남아 있는 상태에서 가져오면 별도 폴더에 추가되어 중복이 생길 수 있으므로, 복구 후 다시 정리합니다.

### 북마크를 삭제하면 휴대폰에서도 사라지나요?

Chrome 동기화가 켜져 있다면 PC에서 삭제한 북마크가 다른 기기에 반영될 수 있습니다. 중요한 북마크는 삭제 전에 HTML 파일로 별도 백업해 두는 편이 안전합니다.

## 한눈에 보기

북마크를 정리할 때는 백업 파일을 먼저 만들고, 폴더별로 URL을 비교한 뒤 삭제 여부를 결정합니다.

| 상황 | 방법 | 주의 |
| --- | --- | --- |
| 같은 북마크가 여러 개 보임 | 이름순 정렬 후 URL 비교 | 이름만 보고 삭제하지 않습니다. |
| 삭제 실수가 걱정됨 | 먼저 HTML 파일로 내보내기 | 백업 파일의 저장 위치를 기억합니다. |
| 다른 폴더에도 중복이 있음 | 모든 북마크 폴더를 하나씩 확인 | 하위 폴더를 빠뜨리지 않습니다. |
| 휴대폰에서도 사라짐 | Chrome 프로필과 동기화 상태 확인 | 동기화 중인 기기의 북마크도 영향을 받을 수 있습니다. |

북마크 정리는 한 번에 전부 지우는 작업이 아닙니다. HTML로 백업한 뒤 폴더 하나를 선택하고, URL이 같은 항목만 비교해 삭제하면 됩니다.
