# notes/ — 원자료 수함

경험 계열 형식(experience, place-log, book-memo, photo-log)을 자동 생성할 때는
사람이 남긴 원자료가 유일한 사실·경험 재료입니다. 모델은 원자료에 없는 경험을
만들 수 없도록 `auto-write`가 강제합니다.

## 사용법

```bash
npm run auto:write "세탁기 일주일 사용기" --topic 일상 --format experience --notes notes/2026-09-washer.md
```

## 원자료 형식 (자유롭게, 아래 항목 정도만)

```
# 2026-09 세탁기 메모

- 날짜/기간: 2026-08-28 ~ 09-04
- 대상/장소/장비: 24kg 일체형, 방 크기와 문 폭
- 그때 알고 있던 것 / 몰랐던 것: 배수 위치를 몰랐다
- 일어난 일 (시간 순서): 설치 지연 40분, 탈수 실패 1회, 수평 조정 후 해결
- 결과와 사실: 소음 체감, 전기요금은 아직 미측정
- 남긴 감상 (선택): 소음은 밤에도 괜찮았다
```

## 규칙

- 원자료에 없는 내용은 글에도 없습니다. 부족한 부분은 모델이 마커로 남깁니다.
- 메모를 그대로 글에 복사하지 않습니다. 모델이 구조와 문장으로 녹입니다.
- 개인정보(주소·전화번호·계정 정보)는 메모에 남기지 않습니다.
- 이 디렉터리의 메모는 개인 원자료이므로 커밋하지 않는 것을 권장합니다 (.gitignore 참고).
